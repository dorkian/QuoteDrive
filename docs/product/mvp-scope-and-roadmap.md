# MVP Scope and Roadmap

## Weekend 1: foundation
Monorepo, Docker Compose, FastAPI/React skeleton, PostgreSQL migration path, seeded demo users, tenant context, dashboard shell, CI baseline.

## Weekend 2: configurable proposal
Customers, opportunities, package catalogue, server-side illustrative estimate, proposal version snapshots, premium comparison UI.

## Weekend 3: controlled AI and approval
Approval flow, audit events, provider abstraction (OpenRouter, Ollama, FakeProvider; automatic fallback deferred), narrative and discovery-brief features, evaluation fixtures.

## Weekend 4: portfolio release
Client-ready preview, responsive/error states, test hardening, architecture diagram, README/runbooks, demo video and first case-study article.

## Deferred
Billing, email sending, PDF rendering, SSO, third-party integrations, real marketplace/catalogue data, public deployment, and autonomous workflow agents.
