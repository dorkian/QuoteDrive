# Personas and Journeys

## Primary journey: proposal to approval
1. A Proposal Manager selects a customer and creates an opportunity.
2. They add approved catalogue packages, quantities, assumptions, and optional services.
3. QuoteDrive calculates transparent, non-binding illustrative estimates on the server.
4. The Manager requests an AI narrative draft from structured, approved inputs.
5. The Manager edits the draft and submits a proposal version for approval.
6. An Approver compares the stable version, comments, and approves or requests changes.
7. QuoteDrive records each relevant event in an audit timeline.
8. The approved version becomes a client-ready preview.

## Demo scenario
Northstar Mobility Advisory prepares an illustrative 12-vehicle mobility-services proposal for fictional customer Lombarda Studio Group. The proposal compares electric, hybrid, and long-distance packages and includes maintenance and roadside assistance. All figures are synthetic planning estimates only.
