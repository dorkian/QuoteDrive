# QuoteDrive v1.0.0

The first complete release of QuoteDrive, a multi-tenant B2B proposal workspace where **AI drafts and people decide**. Everything in it is synthetic demo data: fictional customers, packages and logos, no real payments, lending, credit or e-signature.

## The journey it covers
Discovery brief → configure packages with a live estimate → AI narrative draft → finalize (frozen) → approval by a second person → client-ready preview → share and record the outcome. Four roles: Admin, Proposal Manager, Approver, Viewer.

## Highlights
- **Estimates are calculated on the server, never by AI.** Versions are immutable once finalized; edits fork a new one.
- **AI you can trust enough to ship.** Untrusted input is fenced, output must match a fixed schema, an output guard rejects figures that are not in the proposal data, and nothing is saved without a person reviewing it. Latest live eval: 93% scenario pass, 97% mean check score, 0 safety failures (qwen2.5:7b). The guard is heuristic, and the report names the weakest scenario.
- **Tenant isolation** with 404 on cross-tenant access, covered by unit tests and a Playwright E2E.
- **A UI that explains itself.** Interactive one-screen dashboard (hand-built SVG, keyboard access, table view), one status colour system with icons, sortable and searchable tables, details in side panels and a customer modal that stack without leaving the page, a "Next step" card, a journey stepper that makes AI drafting obvious, and a skippable first-visit tour with tips.
- **Customer profiles.** Generated logo marks, website, headquarters, size, about, tags and a primary contact. The profile (never the contact's email) also feeds the AI prompts, so drafts use the customer's industry, size and contact name.
- **Delivery evidence.** 8 ADRs, API contract, data model, runbooks, a plan-vs-built audit, scored AI evals, Playwright E2E, coverage floors and a gitleaks scan of the full history.

## Upgrade and demo data
Run the additive migrations, then optionally seed richer demo data:

```bash
docker compose exec api alembic upgrade head
docker compose exec api python -m scripts.seed_demo_history
```

`seed_demo_history` adds fifteen fictional customer stories and fills fictional profiles for all 16 customers. It is safe to re-run and only fills empty fields. This release adds migration `c9d4e7a1f2b8` (nine nullable columns on `customers`).

## Known limitations
- If the submit dialog is closed after a partial failure and the page is reloaded, a version can wait on "Awaiting approval" with no approver. It is documented and recoverable.
- E2E runs manually, not on every PR (re-enabled at sprint end, QD-411).
- AI quality with the customer-profile prompts was covered by unit and guard tests, not re-scored live.
- Out of scope for v1: public deployment, SSO, email sending, PDF rendering, integrations. See the README for the full list.
