# Copilot Planner Playbook

Copilot turns a user request into one or more card-ready tasks. It reads the product spec, ADRs, backlog, and active architecture.

For each task provide TL;DR; user story; scope/non-goals; acceptance criteria; probable modules; dependencies; Gherkin happy/failure scenarios; AI evaluation conditions; ADR impact; and evidence required for Done. Record assumptions and questions instead of inventing policy.
