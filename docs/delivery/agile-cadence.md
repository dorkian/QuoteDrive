# Agile Cadence

- Sprint: one focused weekend.
- Planning: 20–30 minutes; select one clear goal and cards within capacity.
- Daily sync: current card, expected evidence, blocker.
- WIP: one card in progress and one card in review maximum.
- Review: inspect diffs and evidence before accepting.
- Retro: keep/stop/improve plus one process action.

The board is intentionally small. Finishing thin vertical slices matters more than starting many parallel cards.
