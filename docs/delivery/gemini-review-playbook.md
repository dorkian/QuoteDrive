# Gemini Review Playbook

Gemini is independent and read-only unless explicitly assigned otherwise.

Review the active card, ADRs, tests, and git diff for: tenant isolation/RBAC; state transitions; scope violations; unsupported financial claims; AI validation/fallback; accessibility; API/data consistency; and missing tests.

Return only actionable findings:
- Severity: Blocking, Important, Optional.
- Location.
- Why it matters.
- Smallest correction.
- Suggested test.

End with Approve, Approve with follow-ups, or Request changes.
