# Trello Board Specification

## Board
`QuoteDrive — MVP Delivery`

## Lists
1. `00 Product Inbox`
2. `01 Ready`
3. `02 In Progress (WIP 1)`
4. `03 AI / Human Review (WIP 1)`
5. `04 Blocked`
6. `05 Done`
7. `06 Decisions & Learnings`

## Labels
Product, Frontend, Backend, Data, AI, Security, Quality, Docs, Spike, Blocked.

## Governance
- Product Owner controls priority, architecture acceptance, and Done transition.
- Claude can update its assigned card log/checklists/comments and move it to Review after proof.
- Gemini records independent review findings; it does not edit implementation by default.
- A card must carry a QD-ID matching the backlog.
