# [QD-001] Create repository, baseline documentation, and local development contract

## TL;DR
Establish the QuoteDrive repository, safety boundaries, agent contracts, ADRs, and delivery rules before implementation begins.

## User story
As the Tech Lead, I want a documented engineering contract so AI-assisted delivery remains safe, focused, and auditable.

## Scope
Included: repository documentation, agent instructions, ADRs, `.gitignore` design, local development contract.
Not included: React/FastAPI application code, external integrations, real credentials.

## Acceptance criteria
- [ ] Product, architecture, ADR, quality, delivery, runbook, and evaluation folders exist.
- [ ] README describes pitch, boundaries, non-goals, and roadmap.
- [ ] AGENTS, Claude, Gemini, and Copilot instructions agree.
- [ ] ADR-001 through ADR-006 exist.
- [ ] Trello card content is ready.

## Test scenarios
Given a new contributor reads README and AGENTS, when they start work, then they understand public-scope and quality constraints.
Given an AI agent starts a task, when it reads instruction files, then it finds tenant, workflow, and AI safety rules.

## Evidence before Done
- [ ] File tree reviewed
- [ ] Markdown links checked
- [ ] No secret values committed
- [ ] Gemini scope review complete
